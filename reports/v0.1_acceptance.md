# 本机知识库 v0.1 验收

日期：2026-09-08。范围为本机个人管理初版，未按多用户团队服务验收。

## 功能

| 功能 | 当前实现 |
| --- | --- |
| 知识问答 | 本地混合检索、可选 AI 拆分、证据预览、DeepSeek 生成与逐条引用、结果导出 |
| 资料入口 | 资料列表与文件名筛选、Markdown 预览与下载 |
| 上传 | Markdown/TXT/DOCX/文字型 PDF；格式与大小检查、内容去重、原稿保留 |
| 文档维护 | 人工确认脱敏后登记、编辑正文并保留版本、可恢复归档、恢复冲突检查 |
| 索引 | 独立构建两路索引、成功后发布、旧版备份、资料变化时暂停旧索引问答 |
| 历史 | 本机持久化问题、答案、来源位置、生成 token 用量与耗时 |
| 反馈 | 质量评价、备注、历史导出 |
| API 设置 | 独立设置页、测试连接、模型配置、Windows 当前用户 DPAPI 加密保存/替换/清除密钥；不保存明文 |
| 外观导航 | 固定五个功能入口、上传快捷入口、回答与来源分栏、明暗模式及本机持久化 |
| 模拟题 | 20 道新题草稿自动生成，可选择与下载，未标注标准答案 |

## 已验证

- 单元测试覆盖引用编号、拒答格式、发送许可、权限防护、历史不保存全文、反馈、编辑版本、归档恢复、上传去重、DOCX 表格、文字 PDF 提取和空白 PDF 拒绝。
- Streamlit 操作测试实际调用本机索引返回片段；检查发送许可、密钥清除、资料页、模拟题页、历史页。
- 生成接口使用模拟 HTTP 返回验证引用、usage 与拒答；这不属于真实在线回答验收。
- 独立目录中使用合成资料实测上传、登记、真实 BM25 + BGE-M3/Qdrant 构建、检索、构建失败时旧索引不变、归档后重建不再返回该文档、恢复后索引变为待更新。
- 正式原始资料未用于上述上传生命周期试验，正式索引未重建或删除。
- 本轮更新通过 24 个单元测试、Streamlit 流程复验和依赖检查。DPAPI 用临时假密钥验证了独立进程读取、替换、清除和损坏报错；UI 测试使用 mock 保存/删除，避免覆盖实际凭据。
- Playwright 检查了真实网页明暗切换、刷新保留主题与资料表格显示；修正了顶部按钮被遮挡和暗色输入提示对比度。截图留在 `_staging/20260908_界面验收/`，不提交 Git。

## 未完成的验收和初版范围外

- 本轮未使用聊天中暴露的旧 Key，新的真实 DeepSeek 回答需要在网页配置新 Key 后验证；线上超时、余额不足等异常仍需账户实测。
- 20 道模拟题没有标准证据标注，也没有盲测成绩。原 15/15 只是已知题的检索结果，不证明新题或生成回答正确。
- 引用编号有效不代表语义支持充分；拒答提示和结构校验也不能保证模型永不编造。
- DOCX/PDF 只提取文字和部分表格，不支持旧版 DOC、扫描 OCR、图片语义或高保真版式。
- 不包含真实团队登录、逐用户权限、公网部署和多进程并发写入；服务监听 127.0.0.1，固定模拟 fde-core 用户。
- 归档是可恢复移动，不提供永久删除。历史按问答次序保存，尚不支持跨轮对话记忆。

## 复验

启动前执行 `python -m unittest discover -s tests -q`；网页流程执行 `python tests/verify_web.py`；真实独立索引流程执行 `python tests/verify_lifecycle.py`。均使用项目 `.venv/Scripts/python.exe`。网页流程会访问真实本机索引，需先关闭正在运行的网页以释放 Qdrant 文件锁。

UI 测试中的生成回答标记为“自动化测试模拟响应”，不得作为业务答案。
